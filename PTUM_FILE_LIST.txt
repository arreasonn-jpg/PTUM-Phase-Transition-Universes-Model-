# Notes
The tracked main.pdf predates the current manuscript corrections and
must not be treated as the current compiled version. LaTeX auxiliary
files and stale compile logs are removed from the correction branch.
The CI workflow is the source of truth for a fresh compiled PDF.
The current scan runner expects 100 trajectories (50 initial conditions
at each of two energy scales); its JSON output is generated at runtime
and uploaded as a CI artifact, not committed as a source file.
The expanding-background linear chi-mode solver is in ptum_floquet.py.
The repository's 10/10 evidence requirements and current gate statuses
are maintained in PTUM_10_OF_10_ACCEPTANCE.md.
